# W07 學習紀錄

## 1. 我的研究問題：想知道什麼？為何想研究？
* **想知道什麼**：如何用 Python 抓取即時天氣資料？
* **為何想研究**：想自己寫小程式抓氣象資料，練習處理 API 字典格式。
---

## 2. API 呼叫與設定：如何抓取資料？
* **API 來源**：Open-Meteo 氣象 API。
* **參數設定**：設定經緯度、要求欄位與時區。
* **程式核心**：用 `requests` 發送請求並轉成字典格式。

---

## 3. 程式碼實作與輸出結果
* **圖表／畫面名稱**：即時天氣查詢結果
* **運作方式**：向 API 請求資料，將時間、溫濕度與風速印在畫面上。
* **看到什麼**：成功顯示即時溫度、相對濕度、體感溫度與日夜狀態。

---

## 4. 我的結論：有哪些資料支持？有哪些限制與未確定事？
* **資料支持**：使用真實連線氣象 API 的即時數據。
* **限制與未確定事**：僅能看當下狀況，無法看長期趨勢，且網路斷線會報錯。

---

## 5. Reflection：學到什麼？原本有何誤解？如何解決問題？
* **學到什麼**：學會用 `requests` 發送 API 請求與解析字典。
* **原本有何誤解**：以為抓網路資料很難、需要複雜金鑰。
* **如何解決問題**：
  * **遇到問題**：印出整包資料太雜亂，找不到目標數值。
  * **解決方式**：查閱說明文件後，學會先抓出指定字典層級再取值。
