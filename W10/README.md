# W10 Student Score Explorer

## 作品說明
這個作品用 Python、Pandas 跟 Streamlit 做了互動式成績查詢網頁。
可以在網頁上輸入名字關鍵字、選班級跟科目、拉分數門檻，再按開始分析看結果。
畫面會算符合條件的人數跟平均分，也會把篩出來的學生資料列出來。
※ 這是用 Streamlit 做的網頁互動工具，不是單純在終端機跑完就結束的腳本。

## 資料來源
程式裡放了 12 筆教學用的假成績資料，欄位有 `name`、`class_name`、`Chinese`、`English`、`Math`。

## 使用技術
Python / Streamlit 互動元件
Pandas / DataFrame / 篩選跟算平均
if/else 條件判斷 / 畫面輸出

## 分析內容
輸入姓名關鍵字找符合的名字。
選班級（全部、101、102）來過濾資料。
選國文、英文或數學其中一科來看。
用滑桿調 0 到 100 分的門檻，再選高於或等於、還是低於門檻。
算符合條件的有幾個人跟平均幾分，沒人符合的話會跳警告。
勾選只顯示符合條件的學生時只看指定欄位，沒勾就看整張表。

## 執行方式
先裝套件：
`python -m pip install streamlit pandas`
再跑起來：
`streamlit run main.py`

## 資料限制
裡面用的是自己寫的測試資料，不是真的學生成績。
結果只看當下輸入的條件算出來，不會存檔也不會寫進資料庫。
